확인일: 2026-10-26. Playwright의 실제 YouTube 플레이어에서 0초부터 재생해 5·15·30·45초 장면을 확인하고, 버퍼 지연 뒤 45초부터 다시 재생해 50·59초를 확인했다. 분석 범위는 0:00~0:59이며 후반 영상은 이 규칙의 근거로 사용하지 않았다. 무음 재생으로 시각 연출을 확인했으며 원본 음성·음악은 청취 분석하지 않았다.

확대율·마우스 속도·자막 크기·내레이션 속도·전환 시간은 원본에서 계측하지 않았다. 아래 값은 새 제작의 시작값이다.

- 1080p, 30fps. 브라우저 UI가 대부분을 차지하고 핵심 조작부를 충분히 크게 유지한다.
- 이동 0.4~0.8초, 먼 이동 최대 1.2초. 곡선은 작게, 시작·도착을 부드럽게 감속한다.
- 입력 100~200ms/글자, 결과 확인 후 0.5~1초 체류. 인위적 오타를 넣지 않는다.
- 줌 1.15~1.45배, 진입·이탈 약 0.6초. 한 기능에 한 번, 전체로 돌아온 뒤 다음 기능을 소개한다.
- 포커스 밖 약 40% 암전, 대상은 원래 밝기. 점·얇은 연결선·최대 두 줄 설명 상자를 빈 공간에 둔다.
- 보라색은 이 참고의 강조색이며 대상 서비스의 브랜드색이라고 주장하지 않는다. 사용자가 다른 브랜드색을 지정하면 맞춘다.
- 장면 전환은 실제 조작을 연결한 컷을 기본으로 한다. 선택적 0.2~0.3초 페이드는 결과를 가리지 않을 때만 쓴다.
- 내레이션은 별도 제작한 차분한 존댓말. 음량 목표 -16 LUFS, true peak -1 dBTP. 원본 음악·대본·자산은 사용하지 않는다.
